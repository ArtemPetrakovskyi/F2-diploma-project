# ВСТУП

## Актуальність теми
Сучасні вебплатформи для інтерактивних карткових ігор вимагають високої швидкості обробки подій, мінімальної затримки (latency) та забезпечення консистентності стану гри при високому мережевому навантаженні. Базові реалізації подібних систем часто обмежені монолітною архітектурою та відсутністю інструментів підтримки прийняття рішень.

Даний проєкт вирішує інженерну проблему побудови відмовостійкої, розподіленої системи реального часу, поєднуючи дуплексний асинхронний зв'язок, фонові паралельні обчислення ймовірностей (Equity Calculator) та інтеграцію RAG-моделей для ретроспективного аналізу ігрових стратегій.

## Об'єкт дослідження
Процес асинхронної обробки подій реального часу та паралельного обчислення ймовірностей у розподілених ігрових вебсистемах.

## Предмет дослідження
Методи побудови подієво-керованої (Event-Driven) архітектури, патерни кешування в пам'яті (Redis In-Memory), алгоритми паралельних симуляцій Монте-Карло та засоби Retrieval-Augmented Generation (RAG) для аналізу логів ігрових сесій.

## Мета роботи
Розробка та архітектурне проєктування подієво-керованої ігрової платформи для підвищення швидкості синхронізації стану гри, забезпечення мінімальної затримки (latency < 50ms) при підрахунку шансів у реальному часі та автоматизації стратегічного аналізу ігрових сесій за допомогою ШІ.

## Завдання проєкту
1. Проаналізувати існуючі аналоги та архітектурні підходи до побудови високозавантажених ігрових платформ згідно з ДСТУ.
2. Обґрунтувати вибір технологічного стеку для реалізації подієво-керованого контуру та RAG-модуля.
3. Спроєктувати розподілену архітектуру системи із використанням UML-діаграм та моделей C4 (Container/Component).
4. Розробити та оптимізувати алгоритм паралельного розрахунку шансів (Equity) на основі симуляцій Монте-Карло.
5. Спроєктувати схему бази даних, шар кешування та користувальницькі інтерфейси платформи.
6. Провести інструментальний аудит якості коду, навантажувальне тестування та перевірку безпеки (Rate Limiting, JWT).
7. Підготувати матеріали для апробації результатів та опублікувати науково-практичну статтю.
