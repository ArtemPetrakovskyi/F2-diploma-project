# Thesis Proposal / Технічна картка проєкту

## 1. Попередня робоча назва (Title)
* **UA:** Розробка подієво-керованої платформи для гри в покер з модулем розрахунку шансів у реальному часі та AI-аналізом ігрових сесій.
* **EN:** Development of an Event-Driven Poker Platform with Real-Time Equity Engine and AI-Assisted Game Session Analytics.

## 2. Актуальність та проблематика (Relevance & Problem Statement)
Сучасні вебплатформи для карткових ігор вимагають високої швидкості обробки подій, мінімальної затримки (latency) та забезпечення консистентності стану гри при високому навантаженні. Існуючі базові реалізації часто обмежені монолітною архітектурою та відсутністю аналітичних інструментів підтримки прийняття рішень для гравців. 

Даний проєкт вирішує інженерну проблему побудови відмовостійкої, високозавантаженої системи реального часу, поєднуючи двосторонній асинхронний зв'язок, фонові паралельні обчислення ймовірностей та інтеграцію мультиагентних ШІ-моделей для детального ретроспективного аналізу ігрових стратегій.

## 3. Сформована ідея продукту (Product Concept)
Розподілена подієво-керована (Event-Driven) мікросервісна/модульна платформа для проведення покерних сесій у режимі реального часу. Система включає дуплексний контур обміну даними, ізольований двигун паралельного математичного моделювання комбінацій та ШІ-сервіс аналізу логів роздач на основі Retrieval-Augmented Generation (RAG).

## 4. Ключові функції (Core Features)
1. **Real-time Game State Engine:** Забезпечення ігрового процесу з мінімальною затримкою через протокол WebSockets/SignalR із обробкою транзакцій стану столу.
2. **Parallel Monte Carlo Equity Engine:** Автономний модуль підрахунку шансів на виграш (Equity) у реальному часі на основі асинхронного симулятора методів Монте-Карло.
3. **In-Memory Session Caching:** Кешування поточного стану ігрових кімнат та оперативностей у Redis для швидкого доступу та синхронізації між клієнтами.
4. **AI Match Analyzer (RAG & LLM):** Інтелектуальний асистент, який аналізує історії роздач (Hand History), виявляє помилки у позиційній грі та надає стратегічні рекомендації.
5. **Event-Driven Audit Logging:** Асинхронний збір та збереження подій гри в базі даних Часових рядів (Time-Series) або документарній СУБД для подальшого аудиту.
6. **Authentication & Security:** Безпечна автентифікація на основі JWT (OAuth2) з обмеженням частоти запитів (Rate Limiting).

## 5. Технологічний стек (Technology Stack)
* **Backend:** C# (.NET Core) / Go (для високозавантажених модулів).
* **Real-Time Communication:** WebSockets, SignalR / gRPC.
* **AI Engine & Analytics:** Python, FastAPI, LangChain / LlamaIndex, OpenAI API.
* **Databases & Caching:** PostgreSQL (основна БД), Redis (Pub/Sub та High-Performance Cache).
* **Infrastructure & DevOps:** Docker, Docker Compose, GitHub Actions (CI/CD), Nginx.
* **Observability:** Prometheus, Grafana.
